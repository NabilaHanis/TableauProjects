Show total sales, profit, and quantity sold for both the current and previous year.

2. Sales Trends
Visualize KPI metrics month-by-month.
Clearly highlight the months with the highest and lowest performance.

Compare sales and profit performance across product subcategories.
Identify top-performing and underperforming segments.

# Things I’ve Learned
1) Dimension & Measure
The number data type could either be a Dimension or Measure. Change it to the proper format according to the purpose of analysis within Tableau. For example, Tableau detect Customer ID as a Dimension, we can change it to DISTINCT[Customer ID]as a Measure to proceed the numerical analysis as we need.

2) DISTINCT COUNT -> Number of Customers in Different Year
Solution: Take the distinct count of Customer ID
Two methods:
a. Drag Customer ID, then choose the Count(Distinct) measure.
b. Type COUNTD('Customer ID')

3) Number of Current Year(CY) Customer & Previous Year(PY) Customer
Solution: Create CY Customer ID and PY Customer ID as new calculated fields. Then, apply these two fields with distinct counts to get the number of CY Customers and PY Customers.
Method:
Press enter or click to view image in full size

4) Level Of Detail (LOD) -> # of Orders per Customer
To get the number of Orders per Customer, group by the Customer ID, then count the distinct value of the Order ID that each Customer ID has. FIXED [CY Customers ID]is doing the step of “group by the current year customers ID”.

5) Filter -> Top 10 Customers by Profit
Select the Customer ID dimension, then click on filter to filter out the Customer ID by CY Profit to get the top 10 customers that generate the highest total profit of the current year.

6) Final Thoughts
Tableau is a powerful data visualization tool that allows flexible changes in each variable. Also, it has great interactivity features for end users to click and select filters to see the changes in trends, ranks and so on.
